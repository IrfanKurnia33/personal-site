# irfankurnia.com

My personal website — built with Astro, deployed from GitHub to Vercel.
The site uses Astro content collections for blog and project pages, plus a
serverless contact form powered by Resend.

## Tech at a glance

- **Astro** with `output: "server"` and `@astrojs/vercel`.
- **Markdown/MDX** content collections for blog and project posts.
- **Self-hosted variable fonts** via Fontsource: Sora, Hanken Grotesk, Azeret Mono.
- **Light/dark themes** with CSS custom properties and a flash-free init script.
- **Serverless contact form** implemented as `src/pages/api/contact.ts`.

## Local development

```bash
npm install
npm run dev        # http://localhost:4321
npm run build
npm run preview
```

> Requires Node 18+ (built on Node 22). No PHP or cPanel is needed.

## Project structure

```
src/
  consts.ts            Site metadata + nav
  content.config.ts    Blog & project collection schemas
  content/blog/*       Blog posts (Markdown/MDX)
  content/projects/*   Project write-ups
  data/                music.ts, podcast.ts, socials.ts
  components/          UI components (Header, Footer, cards, ThemeToggle…)
  layouts/             BaseLayout
  pages/               Routes (index, about, now, blog, projects, music,
                       podcast, socials, contact, 404, rss.xml)
  pages/api/           Serverless API route for the contact form
  styles/              tokens.css (design tokens), global.css, prose.css
public/
  favicon.svg, robots.txt
```

## Adding content

- **Blog post:** add `src/content/blog/my-post.mdx` with frontmatter
  (`title`, `description`, `pubDate`, optional `tags`, `heroImage`, `draft`).
- **Project:** add `src/content/projects/my-project.md`
  (`title`, `description`, `order`, optional `tech`, `year`, `cover`, `url`).
- **Music / Podcast / Socials:** edit the arrays in `src/data/`.
- **Images:** place them next to content or in `src/assets/`; Astro optimizes them.

## Deploying to Vercel

1. Push the repository to GitHub.
2. Connect the repository to Vercel and deploy the main branch.
3. Add these Vercel environment variables:
   - `RESEND_API_KEY`
   - `CONTACT_FROM`
   - `CONTACT_TO`
   - `CONTACT_SUBJECT_PREFIX` (optional)
   - `CONTACT_ALLOWED_ORIGINS`

### Local form testing

Run the site locally with env vars in your shell:

```bash
npm install
npm run dev
```

Open `http://localhost:4321/contact/` and submit the form.

## Notes

- `dist/` is generated by `npm run build` and does not need to be committed.
- `public/` contains static assets such as `favicon.svg` and `robots.txt`.

## Before going live

- Set the production domain in `src/consts.ts` (`SITE.url`).
- Update social links in `src/data/socials.ts`.
- Replace placeholder content in About/Now and blog/project samples.
- Optionally add `public/og-default.png` (1200×630) for social preview cards.
